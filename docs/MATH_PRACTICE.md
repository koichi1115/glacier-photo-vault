# けいさん れんしゅう（小1むけ 音声こたえ ドリル）

小学1年生むけの、**くりあがり・くりさがりのない たしざん / ひきざん** を
ランダムに出題し、**音声（こえ）で回答**できる練習ページです。

- URL: `/math`（ログイン不要・バックエンド不要）
- 実装: `frontend/src/features/math/`
- データ保存: ブラウザの localStorage のみ（サーバーには送信しない）

## 画面

| 画面 | 内容 |
| --- | --- |
| ホーム | レベル / しゅるい / もんだいのかず / 音声・音・読み上げの設定 |
| クイズ | 3カウントダウン → 出題。音声またはテンキーで回答、1問ずつタイム計測 |
| けっか | 正解数・合計タイム・1問あたり・まちがえた問題・1問ずつのタイムバー |
| きろく | 正解率とタイムの推移グラフ、ベストタイム、セッション履歴（タップで詳細） |
| にがて ぶんせき | まちがえやすいパターン、よくまちがえる問題、時間がかかる問題 |

## 出題ロジック（`problems.ts`）

くりあがり無しの足し算は「各位の和が 9 以下」で作れる。引き算はその足し算を
逆向きにする（`a + b = c` → `c - b = a`）ことで、くりさがり無しを保証している。

| レベル | 範囲 | 例 |
| --- | --- | --- |
| レベル1 | 1けた（こたえは 9まで） | `3 + 4`, `8 - 5` |
| レベル2 | 20まで（くりあがりなし） | `12 + 7`, `19 - 6` |
| レベル3 | 100まで（2けた） | `23 + 45`, `96 - 35` |

しゅるいは「たしざん / ひきざん / まぜこぜ」、問題数は 5 / 10 / 20 問。
`0` を含む問題は約 15% 程度に抑え、直前とまったく同じ問題は出さない。

## 音声入力（`useSpeechRecognition.ts` / `japaneseNumber.ts`）

- Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`, `ja-JP`）を使用。
  Chrome / Edge / Safari で動作し、マイク許可が必要。
- 無音で自動停止しても、練習中は自動で聞き直す。
- 認識テキストは「15」「じゅうご」「十五」の3表記すべてを数値化する。
  数え上げてから答える子が多いため、**最後に言った数**を回答として採用する。
  アラビア数字 > 漢数字 > かな の優先順で判定し、「8に」の助詞「に」を
  2 と誤読しないようにしている。
- 確定結果（final）は即判定。途中経過（interim）は 1.1 秒変化がなければ確定扱い。
- 聞き間違いのときは、まちがい表示中の「もういちど いう」で 1 問やり直せる
  （記録も差し替わるので統計が汚れない）。
- 非対応ブラウザ・マイク不許可でも、画面下のテンキーでそのまま回答できる。
- 「もんだいを よみあげる」を ON にすると読み上げ中はマイクを止め、
  自分の声（問題文）を回答として拾わないようにする。

## 統計（`storage.ts`）

1問ごとに `left / right / operation / answer / given / correct / ms / input / patterns`
を保存し、次を集計する。

- **パターン別**: 「たしざん（こたえが2けた）」「5いじょうを たす」「0 が でてくる」
  「こたえが 0」「1 を たす・ひく」「おなじ かず どうし」「2けたの かずを つかう」など。
  まちがい率を主、平均解答時間を従にした「にがて度」で並べ、練習のヒントを表示する。
- **問題別**: `2 + 16` のように、まちがえた回数・答えてしまった数・平均タイム。
- **タイム**: セッション合計 / 1問あたり / 全問正解時のベストタイム（レベル・しゅるい・問題数ごと）。

履歴は最大 200 セッション保持し、「きろくを ぜんぶ けす」で削除できる。
